### Git Configuration
Set up git configuration
```sh

```
In order to verify the configuration has correctly been added:
```sh
git config --list --show-origin                                                                                                                                                
```
### Branching strategy
Use *trunk-based-development*:
- Short-lived feature branches:
  - `feature/<short-desc>`
  - `tech_debt/<short-desc>`
  - `bug/<short-desc>`
